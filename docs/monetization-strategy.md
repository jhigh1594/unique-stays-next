## Confirmed Direction

**Curated guide model.** Not a marketplace. Not Airbnb competitor. The curated guide IS the top of the funnel. SaaS tools are the product.

**No display ads.** Monetization through tools that add value, not ads that extract attention.

## The Flywheel

```
Content Engine (SEO, Journal, Instagram)
         │
         ▼
    Traffic & Audience
         │
         ▼
  ┌──────────────┐
  │  Traveler    │◄──── Data on what travelers want
  │  Tools       │      (preferences, booking patterns, seasonality)
  │  (AI Trip    │
  │   Planner)   │────► More trips planned
  └──────┬───────┘
         │
         ▼
  More bookings → More affiliate revenue
         │
         ▼
  Hosts see traffic from us
         │
         ▼
  ┌──────────────┐
  │  Host Tools  │◄──── Benchmarking data from all stays
  │  (Dashboard, │      (pricing, occupancy, listing quality)
  │   Insights,  │
  │   10-Star)   │────► Better stays → better recommendations
  └──────┬───────┘
         │
         ▼
  Deeper data → Better traveler tools → More travelers
         │
         ▼
      [loops back to top]
```

**Every interaction makes the flywheel spin faster.** More AI trips planned → more unique listings recommended → more affiliate bookings closed → more host data → better recommendations → more trips planned.

## Product Roadmap

### Phase 1: Foundation (Now → Month 3)

**What's running:**
- Programmatic SEO (250 spoke/state pages)
- Journal pipeline (2-3 articles/week, automated)
- Instagram via Buffer (3 posts/week, story-driven)
- 352 stays in database, 35 journal articles published

**Build this quarter:**
1. **Airbnb Affiliate Enrollment** — Add tracking to all "Book" links. First dollar with zero engineering.
2. **AI Trip Planner (MVP)** — Input: region, dates, budget, vibe, party size. Output: full itinerary with unique stay + activities + driving route. Free tier: 1 trip plan. Paid tier: unlimited + saves + sharing + price alerts ($9-15/month or $79/year).
3. **Email Capture** — Trip planner doubles as lead gen. "Save your trip plan" = email address.

### Phase 2: Host Tools (Months 3-6)

1. **Featured Listings** — $50-100/month for "Editor's Pick" badge, priority in category/state searches. Fastest host revenue.
2. **Listing Optimization Report** — $25-50 one-time. Benchmark their Airbnb listing against our 352+ stay database. Photo quality, description, pricing, review sentiment analysis.
3. **Host Performance Dashboard (Beta)** — Pull data from PMS integrations (Hostaway, Guesty, OwnerRez) + our platform. Pricing intelligence, occupancy benchmarking, guest experience insights, 10-star curation framework.

### Phase 3: Scale (Months 6-12)

1. **Host Dashboard GA** — Full launch with tiered pricing ($29-99/month based on features).
2. **Trip Planner enhancements** — Group trip planning, seasonal recommendations, price alerts, "similar stays you'd love."
3. **Sponsored Content** — State tourism board partnerships ($500-2K per guide). We have the audience; they have the budget.
4. **Newsletter** — Weekly curated stays + trip ideas. Sponsored by outdoor/travel brands. $500-1,500 per issue at 5-10K subscribers.

## What Makes This Defensible

1. **Data moat** — Every trip planned, every host benchmarked, every booking tracked makes our recommendations better. This compounds. Competitors can copy the UI but not the data.

2. **Editorial authority** — 200+ journal articles + 1,000+ programmatic pages = SEO dominance in the "unique stays" vertical. This takes years to build and can't be shortcutted.

3. **Network effects on supply side** — More hosts on the dashboard = better benchmarking data = better insights = more hosts join. The data flywheel is the moat.

4. **Two-sided compounding** — Traveler tools and host tools feed each other. Neither is as valuable alone as they are together.
