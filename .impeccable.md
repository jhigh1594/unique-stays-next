# UniqueStaysUSA — Impeccable Design Context

## Design Context

### Users
Curious travelers and aspiring adventurers discovering the site through search, newsletter, or social. They already know they want something extraordinary — they're looking for permission to book it. The job-to-be-done: find a stay that makes a great story. Secondary: trust that what they're clicking through to is genuinely vetted by someone with taste.

### Emotional Arc
Every page layers three emotions in sequence:
1. **Desire first** — the hero image and immersive split hits viscerally and immediately
2. **Trust through editorial** — the curation voice builds confidence that this isn't just a listing
3. **Story as the thread** — the page unfolds like a travel dispatch, each section revealing something new

### Brand Personality
**Wanderer · Editorial · Nostalgic**

UniqueStaysUSA is "The Wanderer's Postcard Collection" — a curated travel editorial masquerading as a directory. The voice is warm, first-person, slightly literary. Think Kinfolk meets Monocle meets a dog-eared travel journal that's been stamped, folded, and mailed twice.

### Reference Points
- **Kinfolk / Monocle Travel** — generous whitespace, photography that breathes, typography as architecture
- **Letterboxd film pages** — editorial and community voice coexisting, data that feels human
- **Physical artifacts** — old travel brochures, passport stamps, vintage postcards, letterpress printing, aged paper

### Anti-References
Generic agency sites, dark-mode SaaS, neon gradients, AI-slop stock imagery, Airbnb/booking-site UI patterns (especially the "sticky card + content" grid pattern everyone uses)

### Aesthetic Direction
- **Colors**: Terracotta (`oklch(0.55 0.14 38)` ≈ `#A84626`), cream, forest green, warm charcoal, sand
- **Type**:
  - **Fraunces** — serif display face; editorial authority, headlines, section titles
  - **Plus Jakarta Sans** — sans-serif body; modern clarity, UI text, metadata
  - **Newsreader** — serif for journal hero headlines; old-press editorial feel
  - **Caveat** — handwritten accent; annotations, informal labels
- **Motifs**: polaroid frames, postage stamps, perforation edges, grain overlays, tilted cards, compass needle, ghost section numbers (I, II, III), letterpress ink texture, wax seal / rubber stamp treatments, filmstrip, postmarks, corkboard pinboards
- **Theme**: Light only
- **Image treatment**: Photos look like developed film — grain, vignette, slight sepia warmth. Never digital-perfect.

### Design Sub-Systems

#### Journal (editorial)
The journal is a full editorial product within the site — a magazine masquerading as a blog. It has its own visual language:
- **Cinematic hero** — full-viewport Ken Burns slideshow, warm tint overlay, word-reveal headline animation, cover strip linking to featured post
- **Corkboard archive** — 3-column polaroid grid with pin-map pushpins, random card tilts, postmark watermarks, desaturated images
- **Dispatch dossier** — individual post cards styled as field dispatches (stamp badges, dashed-rule metadata, paper-map placeholders)
- **Evidence photo** — in-post hero images styled as photographic evidence with polaroid padding and caption
- **Telegram sidebar** — metadata block styled as a telegraph dispatch with stamp seal
- **Reading compass** — fixed-position SVG compass that tracks scroll progress
- **Journal-specific palette** — paper, ink, muted, accent, green, white vars scoped to `.journal-*`

#### Stays (directory)
- **Polaroid cards** — white frame, caption with ruled-line background, grain overlay
- **Stay cards** — tilted with hover lift animation, warm shadows
- **Platform badges** — color-coded by platform (Airbnb coral, VRBO blue, Wander green, Direct neutral)
- **Category pills** — stamp-style active state, bordered inactive state
- **Filmstrip section** — horizontal carousel with drag cursor

#### Navigation
- **Custom compass cursor** — SVG compass needle replaces default cursor; terracotta on light sections, white-ring on dark sections
- **Scroll progress** — reading progress indicator
- **Loading splash** — brand-aligned loading state

### Accessibility Target
**WCAG 2.1 Level AA**
- 4.5:1 contrast ratio for body text, 3:1 for large text and UI components
- Full keyboard navigation
- Screen reader support with proper semantic HTML and ARIA labels
- `prefers-reduced-motion` — all animations and transitions disabled; elements render in final state
- Alt text on all meaningful images
- Focus indicators visible and brand-aligned

### Design Principles

1. **The page IS the artifact** — don't decorate with postcard motifs; render the page as if it IS a vintage travel artifact. Aged paper textures that look real, postmarks that look stamped, perforations that look cut.

2. **Typography breaks the grid** — Fraunces at large scales does unexpected things. Titles that run wide, pull quotes that interrupt the flow, ghost numerals that sit behind sections. Type is layout.

3. **Trust signals look handmade** — ratings as rubber-stamp seals, editorial attribution as inked type, not badge components. The handmade quality is the trust signal.

4. **Story as throughline** — ghost section numbers (I, II, III) give the page a quiet editorial arc: arrival → why it matters → the practical → go. Never just stacked sections.

5. **Motion earns its keep** — only animate when it communicates meaning. Polaroid thumbnails tilt slightly on hover. Gallery transitions between photos. Cinematic hero with Ken Burns reveals the destination. Nothing gratuitous.

6. **Performance is part of the aesthetic** — a laggy site breaks the calm, curated feeling. CSS-first, native-first wherever possible.
